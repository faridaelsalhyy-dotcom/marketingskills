# Tech Pack Template

A page-by-page template. Produce it as a spreadsheet (Excel/Google Sheets), a PLM system (e.g., Centric, Backbone, Techpacker), or a PDF built from Illustrator. Every page carries the same header block.

## Header Block (every page)

```
Brand: ______________   Style #: ______   Style name: ______________
Season: ______   Category: ______   Base size: ___   Units: cm / in
Designer: ______   Tech designer: ______   Factory: ______
Version: v__   Date: YYYY-MM-DD   Stage: Proto / Fit / SMS / PP / Production
```

## Page 1 — Cover

- Front and back flat (or photo of sample)
- Style description (1–2 lines): "Relaxed-fit single-breasted blazer, notch lapel, two-button, flap pockets, fully lined"
- Fabric summary: main fabric, composition, weight
- Size range: e.g., XS–XL (base M)
- Colorways: list
- Target FOB and target retail
- Delivery / drop

## Page 2 — Technical Flats

- Front view, back view (side/interior as needed)
- Numbered callouts to detail pages
- Scale note: "Drawn on size M croquis"

## Page 3 — Detail Callouts

Close-up drawings with measurements for:

- Collar / neckline construction
- Pocket dimensions and placement (from a fixed point — e.g., "pocket top edge 22 cm from HPS, 6 cm from CF")
- Closures: button spacing, buttonhole size and type (keyhole, straight), zip length
- Cuffs, plackets, hems
- Topstitch widths

**HPS** = high point shoulder (where shoulder seam meets neck); **CF/CB** = center front/back.

## Page 9 — Artwork / Print / Embroidery

- Artwork file name and version (vector: .ai / .pdf / .svg)
- Technique: screen print, DTG, heat transfer, embroidery (stitch count), jacquard, all-over print
- Size (W × H) per size range if scaled
- Placement from a fixed point (e.g., "centered on CF, 8 cm below neck seam")
- Colors with standards
- Strike-off required: yes/no

- Tissue, polybag, size sticker, barcode (UPC/EAN) placement
- Hangtag attachment
- Carton: units per carton, size assortment (ratio pack), carton markings
