# Trend Report Template

Use this structure for seasonal trend reports and single-trend go/no-go calls.

## 1. Executive Summary

- Season and horizon (e.g., "Spring/Summer 2027, womenswear contemporary, 25–40, mid-premium")
- The 3–6 key themes in one line each
- The single biggest commercial recommendation
- The single biggest risk

## 2. Macro Drivers

2–4 drivers, each with:

- **Driver** — e.g., "Economic caution after price inflation"
- **Consumer behavior it creates** — e.g., "Buying fewer, better, more versatile pieces"
- **Fashion expression** — e.g., "Elevated basics, investment outerwear, cost-per-wear messaging"

## 3. Key Themes (one section per theme)

```
THEME NAME: [2–3 word evocative name]
Narrative: [1–2 sentences — the mood and the "why"]
Macro driver(s): [which driver(s) feed this]
Lifecycle stage: [Introduction / Rise / Peak / Decline / Revival]
Evidence: [3+ signals from different source types, with dates]

Color:       [4–8 colors with Pantone/Coloro refs + role: neutral/accent/hero]
Materials:   [fabrics, weights, finishes, hand-feel]
Silhouette:  [shapes, volumes, lengths]
Details:     [trims, closures, construction]
Print:       [motifs, scale, technique]
Styling:     [how it's worn]
Key items:   [5–8 specific garments]

Commercial translation:
- Intensity: [directional / commercial / core]
- Categories + price tiers
- Suggested share of range: [%]
- Delivery / drop
- Scale-up signal: [...]
- Pull-back signal: [...]
```

## 4. Trend Validation Scorecard

Score each theme 1–5 per criterion. Weight to the brand's positioning.

| Criterion | Weight (leader) | Weight (follower) | Theme A | Theme B |
|---|---|---|---|---|
| Driver depth | 20% | 15% | | |
| Source breadth | 15% | 20% | | |
| Momentum | 15% | 25% | | |
| Customer fit | 25% | 20% | | |
| Commercial translatability | 15% | 15% | | |
| Longevity | 10% | 5% | | |
| **Weighted score** | | | | |

**Interpretation:** 4.0+ = invest; 3.0–3.9 = test in a capsule; below 3.0 = watch list or skip.

## 5. Color, Material & Silhouette Direction (summary)

- **Palette** — consolidated seasonal palette split into core neutrals / accents / hero colors with approximate unit share
- **Material story** — key fabrics and finishes, sustainability options (certified cotton, recycled synthetics, TENCEL™ lyocell, etc.)
- **Silhouette shifts** — what's getting bigger/smaller, longer/shorter, looser/tighter vs last season

## 6. Watch List

Emerging signals not yet strong enough to invest in, with the evidence that would promote them.

## 7. Out / Declining

Trends to reduce or exit, with markdown-risk warning.

## 8. Sources & Date

List every source and the date the data was pulled. Forecasts decay; readers must know how fresh the evidence is.
