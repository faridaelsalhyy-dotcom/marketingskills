# Range Planning

How to turn a design concept into a balanced, sellable collection plan.

## Range Plan Matrix

Build a matrix before finalizing designs. One row per style.

| Style # | Style name | Category | Role (hero/key/core) | Delivery | Fabric | Colorways | Sizes | Target retail | Target cost | Margin % | Planned units |
|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | |

Then summarize the plan by each dimension and check the balance.

## Balance Checks

### By Role

| Role | Options (target share) | Units (target share) | Notes |
|---|---|---|---|
| Hero / statement | 10–20% | 5–15% | Low units, high visibility |
| Key / fashion | 30–40% | 30–40% | Seasonal best sellers |
| Core / essentials | 40–50% | 45–60% | Carryover blocks in new colors/fabrics |

### By Category

Base category mix on the customer's wardrobe and the brand's strengths. Example for a contemporary womenswear brand:

| Category | Share of options |
|---|---|
| Tops & shirts | 25–30% |
| Dresses | 15–25% |
| Bottoms | 15–20% |
| Knitwear | 10–15% |
| Outerwear & jackets | 10–15% |
| Accessories | 5–10% |

Use own sales history where it exists; it outranks any rule of thumb.

### By Price Tier

| Tier | Share of options | Purpose |
|---|---|---|
| Entry | 25–35% | Accessible trial |
| Core | 40–50% | Volume and margin |
| Hero | 15–25% | Brand statement and anchor |

### By Color

Confirm the unit split matches the color story roles (neutrals ~50–60%, mid tones ~25–35%, accents ~5–15%). Every colorway on a style should have a reason; a color used on only one style is costly to dye and hard to merchandise.

### By Fabric

- Each fabric in 2+ styles (MOQ efficiency and cohesion)
- Total fabric count kept small (commonly 6–12 for an emerging brand's season)
- Check fabric minimums against planned units per fabric

### By Outfit (Wearability)

- Every top should pair with at least 2 bottoms in the range, and vice versa
- Count complete outfits the range can create — more outfits means higher units per transaction
- Merchandise by delivery so each drop is outfit-complete

## Carryover Strategy

- **Carryover (NOS — never out of stock)** — proven core blocks, re-issued season after season with new colors or fabrics
- **Evolved** — last season's best sellers updated with one change (length, fabric, detail)
- **New** — fresh designs; highest risk

A healthy emerging-brand balance is often ~30% carryover/evolved and ~70% new, shifting toward more carryover as the brand's best sellers prove themselves.

## Line Review

Run a line review before committing to samples and again before production:

1. Walk the full range in running order (drawings or samples on rails)
2. Check against the concept and cohesion scorecard
3. Check the balance tables above
4. Check costing vs target margin for every style
5. Decide per style: **keep / modify / drop**
6. Confirm the final count and the tech pack list

**Edit criteria:** drop styles that are redundant (too similar to another), off-concept, can't hit target cost, or have no clear customer occasion.
