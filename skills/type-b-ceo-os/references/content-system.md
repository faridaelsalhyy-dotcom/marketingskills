# Content Operating System

Content is attention **and** an asset the media buyer can test. Track both attention metrics and business metrics. Viral is not profitable by default.

## Pipeline

`ID → Idea → Objective → Funnel stage → Format → Hook → Script → Shoot date → Edit → Publish → Organic performance → Paid test → Paid performance → Revenue → Learning`

Statuses: `idea · scripted · scheduled-shoot · shot · editing · ready · published · paid-test · scaling · retired`.

ID format: `C-<number>`; creative variants `C-0042-v2`; drop link `D1`. Every ad references a content ID so spend rolls up to content ROI.

## Full Content Description Template

Every planned piece gets a description at this depth. This is the "end result" a content brief should reach before anyone shoots.

```
CONTENT ID:      C-0007
TITLE:           (working name)
CATEGORY / STAGE: Humor · TOFU
OBJECTIVE:       One only. (e.g. reach new Type B-coded audience; saves; link clicks)
DROP / PRODUCT:  D1 · Set (or "none – brand")
PLATFORM / FORMAT: IG Reel + TikTok, 9:16, 18–25 s
AUDIENCE MOMENT: The exact situation she's in (e.g. "30 min before leaving, outfit not chosen")
HOOK (0–2 s):    Spoken + on-screen text + visual. Provide 3 alternates.
STORY BEATS:     1) ... 2) ... 3) ... (turn/punchline) 4) product moment if any
SCRIPT / VO:     Full lines in TYPE B voice
VISUAL CODES USED: Palette · symbol · prop · lighting · framing (from the brand world doc)
PRODUCT PRESENCE: Hero / supporting / none. If product: fit and styling points shown
CAPTION:         Hook line + 1 line context + CTA. 2 alternates.
CTA:             Soft (save/send to a friend) or hard (shop link). Match to stage.
SOUND:           Original VO / trending audio (check licensing for ads) / music
LOCATION / PROPS / WARDROBE / CAST: list
SHOOT:           date · duration · shot list · B-roll list
EDIT NOTES:      pacing, captions, cut points, version cuts (6 s / 15 s / 30 s)
SUCCESS METRICS: attention (3-s hold, watch time, shares, saves) + business (clicks, ATC)
PAID PLAN:       Boost-test? Yes if organic beats the account median on shares/saves; budget cap; kill rule
COST:            talent · crew · editor · location · props · creator · total
RISKS:           brand safety, usage rights, sizing/stock constraints
LEARNING (fill after): what the data says, what changes
```

## Hooks Library Structure (create 30+ and tag each)

Hook types: *Recognition* ("POV: you said 5 minutes"), *Confession*, *Contradiction*, *Mini-drama*, *Outfit-in-chaos*, *Founder reveal*, *Anti-trend*, *Behind-the-scenes honesty*, *Fit/fabric demo*, *Social proof*. Tag each hook with the Type B trait it expresses so the brand stays consistent.

## 30-Day Starter Plan (replace with her real drop dates)

| Week | Goal | Pieces | Notes |
|------|------|--------|-------|
| 1 — World | Make the girl recognizable | 3 humor, 1 brand-world, 1 founder, 1 BTS | No hard CTA; measure shares/saves; collect hooks that over-index |
| 2 — Tease | Build demand for the drop | 2 product-teaser, 2 humor, 1 sample/fitting BTS, 1 waitlist push | Capture emails/WhatsApp; no stock promises beyond known units |
| 3 — Launch | Convert | Hero editorial, 3 product, 2 styling, 2 UGC/seeding, launch-day live/story set | Pair with campaign plan (`campaign-and-pro-ads.md`) |
| 4 — Prove & Learn | Social proof + retros | 3 UGC/customer, 1 restock/limited-stock, 1 retro | Fill `Learning`; update hook library and benchmarks |

Cadence is a starting assumption (≈6–9 posts/week across formats); tune to production capacity and cost per piece.

## Content ROI

```
production_cost = sum(photographer, videographer, editor, model, stylist, location, props, creator, boosting)
cost_per_1k_reach, cost_per_save, cost_per_link_click
paid_cpa_for_content = spend on content ÷ purchases attributed (platform) — read with Shopify view
```

Separate:
- **Short-term performance:** clicks, ATC, purchases (direct + assisted).
- **Long-term brand value:** shares, saves, branded search lift, follower quality, repeat reach. Report these separately; do not judge a brand asset on last-click revenue alone.

## Weekly Content Review (15 min)

1. Top 3 by shares/saves (brand signal) and top 3 by link clicks/ATC (commerce signal).
2. Which ones deserve a paid test?
3. Which hook/format/category is over-indexing? Shift next week's mix.
4. Cost per piece vs. result: anything to stop making?
5. Update the `Content` tab and the hook library.
